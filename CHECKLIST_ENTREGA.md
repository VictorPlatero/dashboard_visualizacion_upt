# Checklist de entrega

- [ ] Crear repositorio público en GitHub.
- [ ] Subir todo el contenido de esta carpeta.
- [ ] Crear servicio en Render usando `render.yaml`.
- [ ] Configurar `RENDER_DEPLOY_HOOK_URL` en GitHub Secrets.
- [ ] Hacer un push y comprobar GitHub Actions.
- [ ] Copiar URL pública de Render.
- [ ] Publicar `ARTICULO_MEDIUM_DEVTO_HASHNODE.md` en Medium, Dev.to o Hashnode.
- [ ] Reemplazar los marcadores de URLs del artículo.
- [ ] Grabar video siguiendo `GUION_VIDEO_5_MINUTOS.md`.
- [ ] Publicar video en YouTube, Facebook o TikTok.
- [ ] Enviar enlaces del artículo y video al grupo de Telegram.
- [ ] Completar `LINKS_ENTREGA.txt`.
- [ ] Comprimir únicamente `LINKS_ENTREGA.txt` si el docente solicita solo enlaces, o entregar este ZIP completo si acepta evidencias adicionales.
